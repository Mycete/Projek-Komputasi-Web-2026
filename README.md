# SipeRaLab (Sistem Peminjaman Peralatan Laboratorium)

Repositori ini berisi kode sumber *frontend* untuk aplikasi web SipeRaLab, yang dikembangkan guna mempermudah proses manajemen dan pencatatan peminjaman inventaris laboratorium. Proyek ini disusun sebagai bagian dari pemenuhan tugas mata kuliah Komputasi Web 2026 di Program Studi Informatika, Universitas Pembangunan Jaya.

**Fitur Utama:**
* **Katalog Peralatan:** Menampilkan ketersediaan perangkat seperti kamera, laptop, dan router.
* **Sistem Peminjaman:** Antarmuka formulir untuk mencatat data peminjam dan barang.
* **Navigasi Intuitif:** Tata letak responsif yang memudahkan pengguna mengakses informasi lab.

**Teknologi yang Digunakan:**
* HTML5
* CSS3
* Vanilla JavaScript
